**Morellonomitoon** is an open-source **manga reader app for iOS**, built using **SwiftUI** and **The Composable Architecture (TCA)**.

---

## 📱 Features

- 📖 Browse and read manga with a clean and simple UI  
- ⚡ Built with SwiftUI for modern, responsive layouts  
- 🧠 App architecture powered by **The Composable Architecture (TCA)**  
- 🧩 Modular feature-based architecture  
- 🔄 Scalable and testable codebase  

---

|------------|---------|

## 🚀 Getting Started

### Requirements

- Xcode 14.0+
- iOS 15.0+
- Swift 5.7+

### Installation

```bash
git clone https://github.com/rasyadh/Morellonomitoon.git
cd Morellonomitoon
open Morellonomitoon.xcodeproj
```

Build and run the app using Xcode Simulator or a physical device.

---

## 🧩 Architecture

Morellonomitoon follows **The Composable Architecture (TCA)** principles:

- Predictable and testable state management
- Modular feature-based architecture
- Clear separation of concerns
- Easy side-effect handling

Learn more about TCA:  
<https://github.com/pointfreeco/swift-composable-architecture>
